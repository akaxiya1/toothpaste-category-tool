LOCAL CATEGORY WORKBENCH

牙膏类目本地选品与定价工具

仅在本机运行，把门店现有牙膏 SKU、候选新品、类目结构、市场快照、定价建议和本地备份放在同一个采购工作台里。

127.0.0.1 本地运行
SQLite 本机存储
支持 Excel / CSV
离线也可用

采购总览

先看这期该买什么、替什么、花多少钱，再往下拆结构和单品。

本期采购任务清单

把系统建议翻译成可执行动作：上新、替换、调价、下架。

结构诊断

按价格带、品牌、功效和系统分层看盘子是否合理，点开即可看明细并直接试改售价。

候选池与品牌机会

把候选新品、单品对比、同品牌缺失爆款放在一页里，减少来回跳页。

热销抓取与辅助采集

热销抓取器

默认抓京东、天猫、小红书、淘宝；会自动扩展多关键词并对连续出现的商品加权。

高级设置：平台 Cookie（按需补充）

抓取会用慢速串行方式执行，尽量降低平台风控概率。

浏览器辅助采集

1. 打开平台搜索页 2. 在控制台运行脚本 3. 把 JSON 粘贴回来

批量粘贴采集

如果浏览器辅助采集也不方便，就把商品标题、价格、销量文本、链接整段粘贴进来，系统会尽量整理成候选池。

至少保留商品名和价格，链接和销量文本有则更好。

候选池总表

候选单品决策详情

选中候选新品后，直接看最接近的在售 SKU、蚕食风险和价格毛利对比。

采购决策单

先看动作，再按需展开市场样本、建议依据和批量调价模拟。

现有 SKU 处置单

默认先看关键定价字段，细节依据折叠到每行详情里。

候选采购决策清单

上新复盘

先把这期需要跟踪的新品和调价动作列出来，后续再逐步补销量复盘闭环。

待复盘清单

先知道哪几款要盯、为什么盯、建议多久后回头看一次。

工具与数据

低频操作统一放这里：导入、模板、备份，以及当前 SKU 工具视图。

建议优先使用模板列名。预览后可手动调整字段映射，再执行正式导入。

导入说明

  • 现有 SKU 导入后会自动计算毛利率、单件毛利额、单克售价和价格带。
  • 候选新品支持半自动录入，可保留来源平台、链接、热度和差异化卖点。
  • 同一条码会提示重复，正式导入时按最新数据覆盖更新。
  • 同名高相似商品会提示疑似重复，方便你确认是否已经在售。
