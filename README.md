# 牙膏类目本地选品与定价工具

这是一个只服务于`牙膏类目本地选品与定价`的单项目仓库。

仓库定位已经固定：
- 当前唯一正式项目：`牙膏类目本地选品与定价工具`
- 当前唯一正式代码线：远端 `main`
- 后续新项目：`不要继续加进这个仓库`

## 当前项目做什么
- 导入现有牙膏 SKU 的 `Excel/CSV`
- 本地维护候选新品库
- 一键抓取京东 / 天猫 / 小红书 / 淘宝热销牙膏并自动入候选池
- 自动匹配候选新品与门店现有 SKU 做对比
- 自动生成新品优先上新 / 替换 / 观察清单
- 输出价格带、品牌、功效、角色定位的结构分析
- 给出售价、毛利率、淘汰 / 观察 / 上新建议
- 生成本地 SQLite + JSON 备份

## 启动

- SQLite 数据库：`data/toothpaste_tool.sqlite3`

## 自动抓取说明
- 在“候选新品库”页面使用“热销抓取器”
- 默认抓取：京东、天猫、小红书、淘宝
- 如平台未登录页面返回结果较少，可粘贴对应浏览器 Cookie 提高抓取成功率

## 新项目管理规则
为了后续不再混乱，这个仓库采用固定规则：

- 一个仓库只放一个项目
- 后续任何新项目都新建独立仓库
- 不在这个仓库里追加第二个项目
- 仓库命名统一建议：`业务对象-用途-tool` 或 `业务对象-用途-mvp`

每个新仓库至少写清楚 4 件事：
- 这个项目是做什么的

- 数据 / 配置放在哪里
- 当前状态：`MVP / 运行中 / 归档`
